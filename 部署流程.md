## 1. 发布流程（每次发版照做）

### 1.1 本地：提交推送

```powershell
cd D:\项目文件\DesignCode-AI
git status                          # 确认要提交的改动
git add -A
git commit -m "feat: 改了什么"
git push                            # 完整推送
git log --oneline -1                # 记下 sha，第 2 步对比
```

### 1.2 服务器：拉代码

```bash
cd /root/DesignCode-AI
git pull                            # 完整拉取（带全部历史）
git log --oneline -3                # 头部应与 1.1 的 sha 一致
git status --porcelain | wc -l      # 必须是 0
```

> 若服务器仓库之前用 `--depth=1` 拉过（`git log` 里显示 `grafted`），一次性补全历史：`git fetch --unshallow`
> `git pull` 报 `local changes would be overwritten` 时，服务器上有未提交改动：先 `git reset --hard origin/main` 再 pull。

#### 冲突处理（服务器一律以远端为准）

```bash
cd /root/DesignCode-AI
git status                                  # 看是「未提交改动」还是「本地提交分叉」
git stash push -u -m "server 改动 $(date +%F-%H%M)"   # 想留证据就先存起来

git reset --hard origin/main                # 无条件以远端为准（服务器不改代码）
git status --porcelain | wc -l              # 0
git stash list                              # 刚才存的那条，确认完再 git stash drop
```

卡在合并中途（`git status` 显示 `unmerged paths`）：

```bash
git merge --abort
git reset --hard origin/main
```

防冲突两条：① 服务器不改代码；② 会变的值放 `.env.prod`（已被 gitignore）而不是改 `config.prod.yaml`。

### 1.3 停服

```bash
systemctl stop designcode-frontend designcode-api
ss -tlnp | grep -E ':(3000|8888) ' || echo ">>> 已下线"
```

### 1.4 编译后端 + 启动

```bash
cd /root/DesignCode-AI/frontend_api
export PATH=/usr/local/go/bin:$PATH
go build -o server.new main.go      # 编译失败就停，老版本不动
mv -f server.new server             # 原子替换
systemctl start designcode-api
sleep 3
systemctl is-active designcode-api  # 期望 active（activating/failed 见第 5 节）
curl -s -o /dev/null -w 'backend :%{http_code}\n' http://127.0.0.1:8888/api/v1/config/options   # 期望 200
```

### 1.5 构建前端 + 启动

```bash
cd /root/DesignCode-AI/frontend
npm ci                              # 严格按 package-lock.json 安装

systemctl stop mysqld               # 2G 机器构建前必须停，否则 OOM
npm run build                       # 脚本已含 NODE_OPTIONS=2048，5~10 分钟
ls -lh .output/server/index.mjs     # 产物必须存在

systemctl start mysqld
sleep 3
ss -tlnp | grep 3306                # 必须有输出（systemctl status 会假 active）

systemctl start designcode-frontend
sleep 2
curl -s -o /dev/null -w 'frontend:%{http_code}\n' http://127.0.0.1:3000   # 期望 200
```

### 1.6 网关（默认跳过，只有 nginx.conf 改过才需要）

```bash
nginx -t                            # 只检查语法，不动线上
nginx -s reload                     # 重新读配置，平滑切换不断连接
```

自动判断要不要跑（拉完代码后执行，没改就跳过）：

```bash
cd /root/DesignCode-AI
git diff --name-only ORIG_HEAD HEAD | grep -qx 'nginx.conf' \
  && nginx -t && nginx -s reload \
  || echo ">>> nginx.conf 未改，跳过"
```

- 只改前后端代码 → **不碰 Nginx**（它只负责转发）
- 改了 `nginx.conf` → 必须 reload，否则进程还在用内存里的旧配置（软链只让文件指向仓库，不会自动生效）

### 1.7 验证

```bash
curl -s -o /dev/null -w 'backend :%{http_code}\n' http://127.0.0.1:8888/api/v1/config/options
curl -s -o /dev/null -w 'frontend:%{http_code}\n' http://127.0.0.1:3000
curl -s -o /dev/null -w 'gateway :%{http_code}\n' http://127.0.0.1/
curl -s -o /dev/null -w 'api80   :%{http_code}\n' http://127.0.0.1/api/v1/config/options
```

四个都 200 后，本机浏览器打开 `http://111.229.28.247`：登录 → 上传 → 区域识别 → 生成任务（进度条要动）→ 代码预览。

## 3. 首次 / 换机环境

```bash
# Go 1.25.5
cd /tmp && curl -fLO https://golang.google.cn/dl/go1.25.5.linux-amd64.tar.gz
rm -rf /usr/local/go && tar -C /usr/local -xzf go1.25.5.linux-amd64.tar.gz
export PATH=/usr/local/go/bin:$PATH && go version
echo 'export PATH=/usr/local/go/bin:$PATH' >> ~/.bashrc

# Node 20 + npm
source ~/.nvm/nvm.sh && node -v && npm -v

# 代码 + GitHub 只读访问（仓库是公开的，走 SSH Deploy Key 最稳）
cd /root && git clone git@github.com:For-The-Ideal/DesignCode-AI.git DesignCode-AI
ssh-keygen -t ed25519 -C "designcode-server" -f ~/.ssh/id_ed25519 -N ""
cat ~/.ssh/id_ed25519.pub     # 加到 GitHub 仓库 Settings → Deploy keys（不勾写权限）
ssh -T git@github.com         # 期望 Hi For-The-Ideal/DesignCode-AI! You've successfully authenticated
```

## 4. Nginx 配置

```bash
# 确认是不是软链（是软链才跟着仓库走）
ls -l /www/server/panel/vhost/nginx/designcode-ai.conf
```

不是软链就改成软链：

```bash
cp -a /www/server/panel/vhost/nginx/designcode-ai.conf /root/designcode-ai.conf.bak
ln -sfn /root/DesignCode-AI/nginx.conf /www/server/panel/vhost/nginx/designcode-ai.conf
nginx -t && nginx -s reload
```

`/root/DesignCode-AI/nginx.conf` 内容：

```nginx
server {
    listen 80;
    server_name 111.229.28.247;

    client_max_body_size 30m;                      # 上传大图，默认 1m 会 413

    gzip on;                                       # 文本压缩
    gzip_min_length 1k;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml;

    location ~* \.(php|cgi|asp|aspx|jsp)$ { return 444; }                      # 扫描探测直接断
    if ($request_uri ~* "(cgi-bin|/\.git/|/vendor/|eval\()") { return 444; }

    location /_nuxt/ {                             # 带 hash 的产物，长缓存
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    location = /api/v1/ui-project/analyze {        # AI 同步接口，超时放宽
        proxy_pass http://127.0.0.1:8888/api/v1/ui-project/analyze;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 600s;
        proxy_send_timeout 600s;
    }

    location = /api/ajaxData {                     # Nuxt 解密转发
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
        proxy_send_timeout 120s;
    }

    location /api/sse/ {                           # SSE 必须给 Nuxt + 关缓冲
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header Connection '';
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 3600s;
        proxy_send_timeout 3600s;
    }

    location /api/ {                               # Go 后端
        proxy_pass http://127.0.0.1:8888/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }

    location / {                                   # 其余给 Nuxt（不要写 Connection upgrade）
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
        proxy_send_timeout 120s;
    }

    access_log /www/wwwlogs/designcode-ai.access.log;
    error_log  /www/wwwlogs/designcode-ai.error.log;
}
```

生效 + 确认加载的是这份：

```bash
nginx -t && nginx -s reload
nginx -T 2>/dev/null | grep -n "client_max_body_size\|designcode-ai"
```

## 5. 报错速查

| 报错 | 修复 |
|---|---|
| `Failed to connect to 127.0.0.1 port 10809` | `git config --global --unset-all http.proxy`；`git config --global --unset-all https.proxy` |
| `Permission denied (publickey)` | `ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519 -N ""` → 公钥加到 GitHub Deploy keys → `ssh -T git@github.com` |
| `go.mod requires go >= 1.25.5` | 装 Go 1.25.5（第 3 节） |
| 后端 `activating` / `failed` | `journalctl -u designcode-api -n 60 --no-pager`；`ss -tlnp \| grep 8888` 看端口占用 |
| 后端 500 / 000 | `sed -i 's/111\.229\.28\.247:3306/127.0.0.1:3306/' /root/DesignCode-AI/frontend_api/config.prod.yaml && systemctl restart designcode-api` |
| `npm ci` 报 lock 不同步 | 本地 `npm install` 后提交 `package-lock.json` |
| `Cannot find module '@oxc-*/binding-linux-x64-gnu'` | 旧 pnpm 遗留，已改用 npm；确认服务器 `rm -rf node_modules` 后 `npm ci` |
| 构建被 `Killed` | 确认已 `systemctl stop mysqld`；`dmesg -T \| tail -20` 看 OOM |
| `ss` 里没 3306 | `systemctl restart mysqld`；`free -m` 看内存 |
| 上传 413 | Nginx `client_max_body_size`（第 4 节） |
| 识别 504 | `analyze` 单独放宽超时（第 4 节） |
| 进度条不动 | `nginx -T \| grep -A3 "location /api/sse/"`，必须 3000 + `proxy_buffering off` |
| 外网打不开但本机 200 | 腾讯云控制台放行 80 |
| `systemctl status mysqld` active 但连不上 | `ss -tlnp \| grep 3306` 为准 |

## 8. 红线

1. 服务器上不改业务代码，一律本地 `git push` → 服务器 `git reset --hard FETCH_HEAD`。
2. 后端不裸跑 `./server`，前端不跑 `nuxt dev`，只用 systemd + 构建产物。
3. 构建前端前停 MySQL，构建后用 `ss -tlnp | grep 3306` 验证。
